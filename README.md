# Portfolio

Personal portfolio site for Frank Lopez, built to showcase data-structures projects and coursework.

## About

Single-page site covering:
- **Projects** — a fleet-management BST/AVL/splay tree system, a mergeable priority queue (leftist/skew heaps), and an open-addressing DNA sequence hash table, all written in C++
- **Skills** — languages (C++, Java, Python, JavaScript), tools/web (HTML, CSS, Vite)
- **Education** — B.S. in Computer Science (minor in Mathematics), University of Maryland, Baltimore County
- **Contact** — email, GitHub, and LinkedIn

## Tech Stack

Plain HTML, CSS, and vanilla JavaScript — no framework or build step required.

## Running Locally

Open `index.html` directly in a browser, or serve the folder with any static file server, e.g.:

```bash
npx serve .
```
